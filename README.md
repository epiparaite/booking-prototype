# Booking.com Host App – Prototype (Team 9)

Clickable HTML prototype of a Booking.com host app, built for a UX course (Team 9 / Pickles).

Open `index.html` in a browser, or view the deployed version on Vercel.

Includes the second-round changes from usability testing:
1. Clearer failed price save (pending change, live price, "Try again – save €75", "Discard change").
2. Cancellation consequences split into For the guest / For you / For money.
3. Status and numbered next steps after a cancellation request, plus a pending card on Home.

Cancellation rules and financial figures are illustrative and not official Booking.com policy.
